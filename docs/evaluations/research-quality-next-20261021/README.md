# Research quality and latency follow-up

The candidate preserves narrowly provable printed facts locally, supplies source-bound conditional mana evidence to selection and review, and compresses repeated context without pruning the retained candidate pool. Semantic review still owns interpretations, deck fit, comparisons and whole-request fulfillment.

The code was frozen at `43258c4f12d3e2d0f9d944779805af18e140d3a7`. The full suite passed 4,506 tests with 34 skipped. Adversarial rounds found and closed source/provenance, stale cache, conflicting record, conditional scope, incomplete-rule and evidence-packing defects. These are bounded code checks, not proof of strategic recommendation quality.

`implementation.json` records implementation and synthetic wire checks. `qa-pilot.json` preserves the first, slower pilot rather than replacing it with a more favorable sample. `qa-followup.json` records the next sample: blind AI reviewers preferred its explanations overall in both cases, but completion was slower (Marchesa 91.6 to 181.5 seconds; Kinnan 98.5 to 104.7 seconds), with higher recorded costs. Both answers remain partial. Smaller synthetic wire size was not a measured latency win.

The follow-up also exposed omitted selector evidence in the actual eight-card Kinnan pool. A further positional-wire packing change preserves all rows, conditions and unknowns in an offline reconstruction; a dedicated live verification is pending.

## What remains unproved

No verified expert strategy source was added. The permissioned signed-review workflow is ready, but an attributable human expert must supply and approve actual material. Ten added development cases are AI-authored; human-independent authorship and adjudication remain absent. Existing AI adversarial reviews are useful counterexample searches, not human-expert certification.

Two conversational cases and one observation per build cannot establish quality noninferiority, reliable latency percentiles, or causal speed improvements. Candidate order, generated prose, provider load and cached tokens can differ. A supported activation-cost fact is not a completed recommendation. Both source freshness and interaction conclusions remain bounded to the supplied local snapshots.

Production has not been changed; this is an isolated QA candidate.
