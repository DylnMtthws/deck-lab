## Conversational workflow

Chat persists per owner and deck. The configured Hugging Face provider runs through the existing gateway and cost ledger. Each turn has at most five model calls, eight typed tools, one standalone Goldfish run and one three-alternative experiment. A call may take up to 60 seconds; the overall turn is bounded to eight minutes. Provider failures are explicit. No deterministic response impersonates live AI.

Tools inspect the deck, search real cards, retrieve card facts and tournament evidence, read/run Goldfish, obtain generator candidates and role targets, validate suggested swaps, and start isolated experiments. Generator targets are heuristics and existing competitive-strategy coverage remains limited. Returned observations, nulls, coverage limits and actual tool outcomes remain evidence rather than instructions.

Suggest mode can research, simulate the unchanged deck, and propose replacements; applying selected swaps is an explicit user action. Automate mode tests exactly three distinct alternatives against one frozen source revision. Each changes one to three physical cards. Copies are stored as private experiment snapshots, not extra decks in the library. Training and independent-seed measurements are retained for baseline and alternatives. The assistant has no tool to adopt into the original deck.

Constraints include a total USD budget (empty means no cap), intended power level, theme, and protected cards. Budget with unknown recorded prices is rejected, protected identity is preserved across printings, and legality is checked in code. Power and theme remain semantic preferences, with unverified rationales explicitly distinguished from measured outcomes. Changing settings or switching modes cancels further work. An in-flight provider/simulator call can finish; no next step starts after cancellation.

Adoption requires an explicit click, source revision matching the frozen baseline, fresh current-constraint validation, and exact tested swaps. The editor updates through its normal history hooks so Undo works. Cumulative changes beyond three since the last successful source simulation require a rerun. Deleting a source deck removes its conversation and experimental snapshots.
