## Deviations / notes
The shipping `tournament_results` table has no event-size column, so the service reports `min_event_size: null`, applies no floor, and the UI says "event size not recorded". If `player_count`, `event_size`, `players`, or `num_players` is present, that column is the floor (default `load_cedh_settings().meta.min_event_size`). `DeckExplanation` has no per-card text, so `reason` is null unless stored JSON also has `card_reasons`, `reasons`, or `cards[].reason`. `DeckCandidate.to_json()` omits `priority`; the service reads it when present and otherwise reports 0. All-time copy says "all time" / "No tournament evidence for this commander" rather than "last 0 days". Badges sit in the row actions so the list grid and the narrow layout keep them visible.
