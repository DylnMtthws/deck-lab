## Deviations / notes
- AC-9 (Amendment 1 fix): The bug was that the status bar stayed blank on page load because `deck-lab-status.js` loaded after `deck-lab:ready` had already fired, so its `ready` listener never ran. Fixed by rendering immediately from `getState()` when `DeckLabBuilder` already exists at script boot time, and only falling back to the `deck-lab:ready` listener when it doesn't. The `else` branch ensures we never render twice for one state on boot.
- The typeBucket ordering returns the FIRST match from `[Land, Creature, Planeswalker, Battle, Instant, Sorcery, Artifact, Enchantment]`. "Enchantment Creature — Pegasus" correctly returns "Creature" since Creature precedes Enchantment.
- The Node harness uses `vm.runInContext` to dispatch entry-button clicks because the fake DOM's `querySelectorAll` does not support descendant combinators (space-separated selectors). Entry button click tests run within the VM context using a simple `children` loop to find the button.
