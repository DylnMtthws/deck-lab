- The same stacks-only scope lifts a few existing chrome sizes (save/undo/redo, Add to, mana symbols, the evidence heading, the account avatar) onto the type scale, and gives the rail's simulation inputs and verdict buttons a non-native surface, so the stacks scenario lint is clean. Those rules do not apply in other display modes.
